# Paper wedding invitation

A paper invitation you can open, pull out, turn over and photograph in your browser.

Production URL: https://wonsik-ha.github.io/paper-wedding-invitation/

The simulated QR camera opens https://wonsik-ha.github.io/wedding-invitation/ directly.

Development: `npm ci`, `npm run dev`. Validation: `npm run test:unit`, `npm run test:e2e`, `npm run build`.

Original invitation artwork is preserved. No real camera access or backend is used.
